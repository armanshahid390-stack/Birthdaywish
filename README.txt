DUMBOOO BIRTHDAY GIFT
=====================

FILES
- index.html: page content
- style.css: layout, colors, animations
- script.js: navigation, candle interaction, gift reveals, confetti and music button

PREVIEW
Open index.html in a browser.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository, for example dumbooo-birthday.
2. Upload index.html, style.css, and script.js (keep all three in the repository root).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published URL shown in the Pages section, then send that URL to your friend.

MUSIC
The music button is ready, but browsers cannot play music that isn't present. For music, add a royalty-free MP3 file named music.mp3 beside index.html. Music starts only after the visitor taps the music button.

PERSONALIZE
Search for "Dumbooo" in index.html to change the nickname. Edit the birthday letter in the section with id="letter". You can edit the gift messages in script.js.

This site uses Google Fonts if the visitor is online; it falls back to system fonts if not.
