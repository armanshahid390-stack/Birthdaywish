MINNY'S LITTLE UNIVERSE — GITHUB PAGES

1. Extract this ZIP.
2. Create a PUBLIC GitHub repository (e.g. minny-little-universe).
3. Upload index.html and the entire images folder, preserving the folder structure.
4. Commit the files.
5. Open repository Settings > Pages.
6. Choose "Deploy from a branch", branch "main", folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. Your link will look like:
   https://YOUR-USERNAME.github.io/minny-little-universe/

The five supplied photos are copied as-is into images/minny1.jpg through images/minny5.jpg.
No facial features were edited, retouched, or regenerated.
